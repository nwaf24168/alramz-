# نظام إدارة الأداء - الرمز العقارية

نظام متكامل لإدارة وتتبع مؤشرات الأداء الرئيسية (KPIs) للشركة، يشمل:
- قياسات NPS للعملاء الجدد والحاليين
- مؤشرات جودة التسليم والصيانة
- معدلات الاستجابة للمكالمات
- مقاييس رضا العملاء
- أداء المبيعات والتحويل
- جودة إدارة المرافق

## المميزات
- إدخال البيانات الأسبوعية والسنوية
- لوحة تحكم تفاعلية لعرض المؤشرات
- واجهة مستخدم باللغة العربية
- دعم كامل للتصميم المستجيب
- تخزين وأرشفة البيانات

## متطلبات التشغيل
1. Node.js (الإصدار 16 أو أحدث)
2. npm أو yarn

## تثبيت المشروع
```bash
# تثبيت الاعتماديات
npm install

# تشغيل المشروع في بيئة التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```
